# Полные инструкции задач Notion → KB

Перенос выполняется отдельно от включения задач. Производственная база, n8n, зарплата и сообщения этим этапом не переключаются.

## Подготовленный локальный объём

- Исходный архив хранит все 41 шаблон календаря, включая неактивные. Пустой `New page` исключён из переноса в задачи по решению владельца.
- 41 выключенная задача после разделения подсвечников и исключения пустого `New page`. У 15 подготовлены чек-листы; у остальных 26 повтор и чек-лист не назначаются автоматически. Суммы и исходные идентификаторы сохраняются.
- 7 ноября владелец подтвердил расширение на всю связанную цепочку: руководства, оборудование, карточки гостей и сотрудников, ассортимент и складские записи. Они сохраняются страницами в отдельном «Архиве Notion», без создания оперативных записей CRM и без начислений.
- Списки записей собираются из связанных представлений баз, включая архивный раздел; фильтрующие представления сверяются отдельно. Текст, свойства, вложенные списки, таблицы, изображения, PDF и другие файлы сохраняются. Общие блоки разворачиваются в содержимое, а ссылки заменяются внутренними ссылками Sheerly. Файлы объединяются по SHA-256; временные подписи скачивания в пакет не попадают.
- Исходная вложенность восстанавливается там, где родитель входит в перенесённую цепочку. Ручные изменения текста, названия, значка и расположения сохраняются. Ранее импортированное изображение, удалённое вручную после начала отслеживания вложений, не добавляется повторно; новые изображения источника дополняют ручной текст. Разрешившиеся заглушки получают настоящее название источника.
- Недоступные страницы и неподдерживаемые элементы обозначаются явно. `pendingPages` и `missingAssets` отражают незавершённый перенос, а не успешное копирование. Итоговый объём сверяется по частному `bundle.json` и отчёту импорта.

В базе знаний сохраняется полный форматированный текст, таблицы, изображения и вложения. Два самостоятельных этапа подсвечников сохраняют свои подготовленные инструкции; исходная объединённая статья находится в связанных материалах. В тексте задач учтены понедельник для уборки за холодильниками и непрерывный цикл четырёх групп холодильников.

## Частный пакет

Не коммитить исходные MCP-ответы: `metadata.references`, свойства файлов и иконки могут содержать временные ключи скачивания. Полный связанный граф содержит персональные и операционные записи: хранить его и файлы только в частном пакете, не коммитить в Git. Расширенный объём подтверждён владельцем 7 ноября.

Подготовка из уже полученных ответов и проверенных файлов:

```sh
# BeautifulSoup 4.13.4, mistune 3.1.3 — отдельное окружение Python.
python scripts/prepare-notion-task-bundle.py CACHE_DIR OUTPUT_DIR
```

Необязательный третий аргумент — JSON-массив идентификаторов для ограниченного набора руководств; исходные шаблоны добавляются к нему автоматически. Без него обрабатывается весь согласованный кеш. Пакет содержит `bundle.json`, файлы по хешам, отметки недоступных источников и предупреждения о пропусках. Временные URL в него не включаются. Имена связанных страниц подставляются в подписи ссылок; даты и флажки показаны привычными значениями, без служебных ключей Notion. Числовой ноль сохраняется. Проверить `missingAssets`, `warnings`, `pendingPages` до применения; наличие страницы-заглушки не означает переноса её содержимого.

## Применение

Сначала применить миграции PR и выполнить исходные `import-notion-tasks.mjs` и `migrate-task-instructions.mjs` для 15 подготовленных задач. Затем:

```sh
node scripts/import-notion-task-bundle.mjs --venue UUID --bundle OUTPUT_DIR
node scripts/import-notion-task-bundle.mjs --venue UUID --bundle OUTPUT_DIR --apply
node scripts/import-notion-task-bundle.mjs --venue UUID --bundle OUTPUT_DIR --verify
```

По умолчанию первая команда только сверяет пакет. `--catalog-only` добавляет исключительно недостающие выключенные шаблоны, без переноса KB. В production для записи дополнительно нужны `--allow-production` и `TASK_INSTRUCTION_ACCESS_TOKEN` владельца. Активный аккаунт и заведение проверяются; локальные seed-реквизиты допускаются только для localhost. Перенос останавливается при включённых задачах, назначениях или ранее включённой обработке.

Страницы создаются и сохраняются через обычный доступ владельца, версии KB и аудит. Файлы загружаются в закрытый `account-attachments` и штатно регистрируются. Задачи связываются со страницами через `schedule_task_command`, с проверкой версии и прав. Сторонние ручные изменения текста сохраняются; недостающие изображения добавляются. Ключи и файлы проверяются до записи, путь вложения ограничен каталогом пакета. Повторный запуск не создаёт дубли.

`state-UUID.json` хранит хеши текста, историю импортированных вложений и одноразовые настройки созданных папок; `hierarchy-UUID.json` — импортированное расположение. При пересборке пакета переносить эти файлы из предыдущего пакета. Текст после ручных правок не становится принадлежащим импорту даже после добавления недостающих изображений. Повторные проходы сохраняют эти правки. Во время применения не редактировать те же страницы параллельно. `--verify` читает все файлы под обычными правами владельца, проверяет SHA-256, наличие каждой страницы архива и разрешимость внутренних ссылок. Чтение страниц и дерева разбито на порции, чтобы архив не обрезался лимитом API. Записи баз показаны штатным списком подстраниц, а не продублированы тысячами абзацев в редакторе. Длинный список раскрывается по 50 записей; поиск инструкции охватывает весь архив и показывает до 50 вариантов с сохранением выбранной страницы. Для новых баз показ подстраниц включён; автоматически созданные пустые папки обновляются один раз, после чего ручное выключение списка сохраняется. Снимки инструкций и доступ сотрудников продолжают использовать штатную изоляцию заданий.

Удалённые в Sheerly шаблоны не восстанавливаются импортом; их исходные идентификаторы сохраняются для защиты от повторного создания. При обновлении стенда с прежним импортом пустой `New page` удаляется через меню задачи.


## Регрессионные проверки

```sh
python -m unittest discover -s scripts/tests -p test_notion_bundle.py
node --test scripts/tests/notion-bundle-content.test.mjs
```

Проверяются общие блоки, форматирование внутри контейнеров, изображения в списках, свойства карточек, даты/флажки/нули, иерархия записей без дублирования текстового индекса, варианты URL Notion, повторные подписанные ссылки на один файл и сохранность ручного текста после нескольких обновлений источника.
