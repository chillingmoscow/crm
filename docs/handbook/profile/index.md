# Профиль

## Что это

Раздел **«Настройки профиля»** (`/profile`) — личные данные текущего
пользователя: фото, имя/фамилия, пол, дата рождения, контакты, адрес.
Эти поля видны всем работодателям, у которых вы работаете.

## Как пользоваться

1. Меню профиля (правый верхний угол) → **Настройки профиля**.
2. Под заголовком — **прогресс-бар заполненности**: показывает одну
   подсказку по следующему незаполненному полю. Когда заполните всё —
   карточка исчезает (и выпадает confetti 🎉).
3. **Фото** меняется кнопкой «Изменить фото» — JPG/PNG до 5 МБ. Если
   загрузка занимает больше минуты — таймаут, увидите подсказку
   «Проверьте подключение».
4. **Email** — поле справа от вашего адреса. Чтобы сменить:
   - Введите новый адрес → **«Сменить»**
   - На новый адрес придёт письмо с одноразовой ссылкой
   - Перейдите по ссылке → email обновится сразу
   - Ссылка действует **1 час** и одноразовая

## Известные ограничения

- Если на проде не настроен SMTP (env vars `SMTP_*` в Coolify) — письмо
  с подтверждением смены email не уйдёт. Юзер увидит сообщение
  «Не удалось отправить письмо для смены email. Проверьте настройки SMTP».
- Старый email НЕ получает уведомление о том, что кто-то запросил смену
  (как у банков). Сделаем позже, если будет нужно.
