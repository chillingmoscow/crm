# Горячие клавиши

## Что это

Экран-справка со всеми сочетаниями клавиш приложения. Открывается из
меню профиля или хоткеем — и показывает сгруппированный список:
«Глобально», «База знаний», «Редактор страницы».

## Для кого / когда использовать

Любой пользователь, который хочет работать быстрее без мыши: открыть
поиск, свернуть меню, форматировать текст в Базе знаний.

## Как пользоваться

1. **Открыть справку:** нажмите `Shift + ?` в любом разделе, либо меню
   профиля (аватар внизу сайдбара) → **«Горячие клавиши»**.
2. Закрыть — `Esc`, крестик или клик по затемнённому фону.
3. На Windows/Linux там, где показан `⌘`, используйте `Ctrl`.

### Доступные сочетания

**Глобально (в любом разделе):**

- `Shift + ?` — открыть эту справку.
- `⌘/Ctrl + K` — поиск по Базе знаний (работает из любого раздела;
  выбор результата переходит на страницу).
- `⌘/Ctrl + B` — свернуть / развернуть боковое меню.

**База знаний:**

- `⌘/Ctrl + K` — поиск по страницам.
- `⌘/Ctrl + Shift + L` — заблокировать / разблокировать страницу.
- `⌘/Ctrl + Shift + F` — добавить / убрать из избранного.
- `⌘/Ctrl + Shift + D` — дублировать страницу.
- `⌘/Ctrl + Shift + P` — создать новую страницу.
- `⌘/Ctrl + Shift + H` — открыть историю версий.
- `⌘/Ctrl + Z` — отменить удаление вида коллекции.
- `⌘/Ctrl + Enter` — отправить комментарий или ответ в треде.
- `Esc` — закрыть композер или всплывающее окно.

**Редактор страницы:**

- `⌘/Ctrl + B` / `I` / `U` — жирный / курсив / подчёркнутый.
- `/` — меню блоков (вставить блок).
- `Enter` — новый блок, `Shift + Enter` — перенос строки внутри блока.

## FAQ / частые ошибки

- **Q:** Нажимаю `Shift + ?` в поле ввода — ничего не происходит.
  **A:** Так и задумано: пока курсор в текстовом поле или редакторе,
  хоткей справки не срабатывает, чтобы не мешать вводу знака `?`.
  Кликните вне поля и нажмите снова.
- **Q:** `⌘ + K` раньше работал только в Базе знаний — теперь везде?
  **A:** Да, поиск по Базе знаний теперь доступен из любого раздела.
- **Q:** Почему «создать страницу» — `Shift+P`, а не `Shift+N`?
  **A:** `⌘/Ctrl+Shift+N` зарезервировано браузером (окно инкогнито) и
  не перехватывается приложением. Поэтому `P` (page).

## Известные ограничения

- `⌘ + K` ищет **только по Базе знаний**. Единого поиска по всем
  модулям (клиенты, финансы и т.д.) пока нет.
- Список хоткеев в справке статический — отражает текущие сочетания,
  переназначить их нельзя.
