# Статьи доходов и расходов

Статьи делят денежные потоки на категории (продажи, аренда, фонд оплаты труда и т.д.). Используются в транзакциях.

## Архивирование и удаление

### Архивировать (inline в списке)

В строке статьи — кнопка с иконкой архива. После подтверждения статья скрывается из всех выборов в новых транзакциях. История по существующим транзакциям сохраняется (категория продолжает работать в отчётах).

**Кто может:** только владелец аккаунта.

### Архив

`/finance/categories/archive` — owner-only. Ссылка «Архив (N)» в шапке списка появляется когда есть архивные статьи.

В архиве:
- **Восстановить** — статья снова появится в выборах.
- **Удалить навсегда** — статья будет удалена из базы. Транзакции, ссылавшиеся на неё, потеряют категорию (станут «без статьи»). История сумм сохраняется.

### Системные статьи

Категории с меткой «системная» — это базовый набор, поставляемый с продуктом. Их нельзя архивировать или удалить.

## FAQ

- **Раньше был чекбокс «Показать скрытые»** — теперь архив на отдельной странице, доступной только владельцу.
- **«Архивировать» не работает на системной статье** — это by design. Системные статьи фиксированы.
