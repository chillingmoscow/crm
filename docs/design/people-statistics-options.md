# Статистика на экранах людей: варианты

31 октября 2026. Это предложения для выбора, статистика ещё не реализована.

## Компактная сводка над списком

Одна невысокая полоса между заголовком и таблицей, без сетки крупных карточек.

- Сотрудники: работают сейчас, принято за месяц, средний стаж действующих сотрудников. Под стажем небольшая горизонтальная шкала по группам: до месяца, 1–3 месяца, 3–12 месяцев, больше года.
- Кандидаты: новые, ожидают собеседования, проходят стажировку. Рядом распределение анкет по текущим этапам.
- Нажатие показателя с однозначным соответствием фильтру применяет этот фильтр к списку. Остальные показатели имеют пояснение расчёта.
- На телефоне показатели переходят в две строки, график остаётся небольшим.

Подходит для быстрого ежедневного обзора. Постоянно занимает место перед списком.

## Обзор по кнопке — рекомендуемый вариант

Нейтральная кнопка с иконкой графика в ряду инструментов. По нажатию раскрывается компактный блок над списком; состояние раскрытия сохраняется для пользователя.

- Сотрудники: состав по должностям и группам стажа. При наличии достоверных дат — принято/уволено по месяцам за выбранный период.
- Кандидаты: распределение по этапам и поступление анкет по неделям; отдельно количество наймов из анкет выбранного периода.
- Достаточно двух простых диаграмм и двух-трёх чисел. Основная таблица остаётся рабочим центром страницы.
- На телефоне диаграммы идут последовательно, без горизонтальной прокрутки.

Подходит для страницы, которой пользуются и для работы со списком, и для периодического анализа. По умолчанию свёрнут.

## Сводка в боковой панели

Та же кнопка графика открывает общую боковую панель со сводкой и выбором периода.

- Сотрудники: стаж и движение команды, затем распределение по должностям.
- Кандидаты: текущие этапы, скорость первого разбора, наймы из анкет выбранного периода.
- Список не сдвигается; на телефоне панель занимает экран целиком.

Подходит, если приоритет — сохранить максимальную высоту таблицы. Одновременно сравнивать сводку и строки менее удобно.

## Определения и ограничения данных

- «Работают сейчас» — действующие сотрудники выбранного заведения; приглашения не входят в штат.
- «Средний стаж» — среднее время с подтверждённой даты трудоустройства у действующих сотрудников. Это не средняя продолжительность завершённой работы.
- «Средняя продолжительность работы уволенных» — от подтверждённого начала работы до увольнения. В текущем наборе данных списка уволенных дата начала не передаётся; для этой метрики нужно дополнить выборку.
- Дата создания/импорта профиля не заменяет подтверждённую дату начала работы. Если дата неизвестна, запись исключается из расчёта стажа, а рядом указывается покрытие данных.
- Диаграмма текущих статусов — распределение, не конверсионная воронка. Этапы можно менять вручную; нельзя выдавать число анкет в каждом текущем статусе за число прошедших этап.
- Конверсия в найм считается для одной группы анкет по дате поступления, с учётом уже принятых сотрудников. Нельзя делить наймы этого месяца на все поступления другого периода.
- Для исторической воронки нужны события и назначения, с отдельной обработкой старых импортированных анкет, у которых история этапов может быть неполной.
- Графики считаются по всей разрешённой выборке, а не по текущей странице таблицы. Сотрудники относятся к заведению, кандидаты общие для аккаунта.
- Конкретные числа и проценты в макетах будут помечены как примеры до подключения расчётов.

Выбор варианта и состава показателей требуется до реализации статистики.
