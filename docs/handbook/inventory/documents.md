# Акты инвентаризации — список

Страница **Документы → Акты инвентаризации**.

## Что это

Список всех актов инвентаризации текущего аккаунта, доступных вашему уровню
доступа. Используется ежедневно: смена начинает счёт, менеджер раздаёт
задачи, владелец смотрит итоги и пересорт. Страница спроектирована как
рабочий стол — в первую очередь видны акты, которые требуют действия именно
от вас.

## Inbox-сортировка по умолчанию

Когда вы открываете список без явной сортировки, акты упорядочены не просто
по дате, а по зонам важности:

1. **Требуют моего действия сейчас** — назначенные вам в статусе «Назначен»
   или «В работе»; для менеджера сюда же попадают акты в статусе «Готов к
   проверке».
2. **Свежие новые** — «Новый» и «Назначен (но не мне)».
3. **В работе у других** — кто-то уже считает.
4. **Готовые** — проведённые и архивные.

Внутри каждой зоны — по дате, новые сверху. Любая ручная сортировка через
заголовок колонки или попап «Сортировка» сбрасывает inbox-режим; кнопка
**Inbox** в строке представлений возвращает дефолт.

## Сохранённые представления

В верхней части страницы — лента кнопок-«видов». Это именованные комбинации
фильтров и сортировки.

**Встроенные:**

- **Inbox** — inbox-сортировка без фильтров (дефолт страницы).
- **Мои назначения** — все акты, где `assigned_to = вы`.
- **Ждут проверки** — статус `ready_for_review`, отсортировано по дате.
- **Готовые** — статус `processed`.

**Собственные:** настройте фильтры под себя и нажмите «Сохранить вид» — кнопка
появится, как только сработает хотя бы один фильтр и активный встроенный
вид не совпадает с текущим. Названия задаются вручную. Удаление — крестик
внутри кнопки.

Виды хранятся локально в браузере, синхронизация между устройствами не
поддерживается (будет позже).

## Фильтры

Пять чипов под шапкой, активные подсвечены брендовым цветом.

- **Заведение** — Все / Не распределённые / конкретное. Пользователь видит
  только заведения своего членства. Право `inventory.view_all_venues`
  расширяет список до всех заведений аккаунта.
- **Статус** — мульти-выбор (Новый / Назначен / В работе / Готов к проверке /
  Проведен / Итоги требуют проверки / Ошибка синхронизации).
- **Исполнитель** — Любой / На меня / Без назначения / конкретный
  сотрудник. Фильтр виден тем, у кого есть право управлять актами; линейный
  сотрудник его не видит — он и так видит только свои назначения.
- **Проверяющий** — Любой / Проверяю я / Без проверяющего / конкретный
  сотрудник. Тоже для управляющих актами; помогает найти «что ждёт моей
  проверки».
- **Склад** — мульти-выбор по складам, доступным пользователю.
- **Период** — пресеты «Весь архив (по-умолчанию)», «7 дней», «30 дней»,
  «90 дней», «Свой диапазон» (два датапикера). По-умолчанию фильтр периода
  отсутствует — видны все акты, новые сверху.

Кнопка **«Очистить все»** справа от фильтров сбрасывает их разом, включая
поиск и сортировку.

## Справка и горячие клавиши

Кнопка **«?»** в верхней панели (слева от колокольчика уведомлений) на всех
страницах акта открывает боковую панель со справкой: роли, статусы,
уведомления.

Клавиша **`?`** открывает шпаргалку горячих клавиш. Она контекстная —
показывает глобальные клавиши и клавиши текущего раздела. Для списка актов:

- `J` / `K` — следующая / предыдущая строка (выделение).
- `Enter` — открыть выделенный акт.
- `/` — поиск.
- `F` — показать / скрыть фильтры.

Клавиши не срабатывают, пока курсор в поле ввода.

## Массовые действия и сумма итогов

Менеджер может выделить несколько актов чекбоксами (или «выбрать все» в шапке
таблицы). В появившейся нижней панели:

- **Сумма итогов по выделению** — нетто-расхождение (излишки минус недостачи)
  по выбранным актам одним числом: плюс зелёным, минус красным. Удобно быстро
  прикинуть итог по нескольким актам (например, выставить размер страницы 100,
  «выбрать все» и посмотреть сумму). Выделять можно **любые** акты, включая
  проведённые — для подсчёта суммы это важно.
- **Назначить исполнителя / проверяющего** и **удалить** — применяются только
  к подходящим актам; проведённые и акты с ошибкой синхронизации пропускаются
  (кнопки недоступны, если в выборке нет подходящих). Назначенному приходит
  одно сводное уведомление, по каждому акту пишется запись в журнал.

Сумма считается по выделенным строкам **текущей страницы**.

## Поиск

Иконка лупы в шапке открывает поле. Минимум — 2 символа, дебаунс 250мс.

Что ищется:

- **№ акта** — частичное совпадение.
- **Комментарий к акту** — частичное совпадение.
- **Названия ингредиентов в позициях акта** — частичное совпадение по
  `document_items.product_name`.

Если совпадение нашлось в позициях, в строке акта появляется чип
«🔍 Coca-Cola» (до трёх совпадений) — чтобы было понятно, _почему_ именно
этот акт попал в результаты.

## Live-обновления

Список обновляется в реальном времени без F5. Если коллега назначил вам
акт или закончил счёт — вы увидите изменение в течение секунды. Это
работает на уровне всех актов вашего аккаунта.

## Действия в строке

- **Клик по строке** — открывает акт. По состоянию:
  - Незаполненный → **Заполнение** (`/documents/inventory/{id}`).
  - Проведённый или с готовыми итогами → **Итоги** (`/documents/inventory/{id}/results`).
- **№ акта (синяя ссылка)** — тот же переход, но явный (для тех, кто привык к
  ссылкам).
- **Колонка «Назначен»** — селектор: меняем исполнителя прямо в строке.
  Виден тем, у кого есть право `inventory.manage_documents`.
- **Меню «⋯»** — «Перейти к итогам», «Перейти к заполнению»; для менеджера
  ещё «Изменить назначение». На мобильном — отдельный bottom sheet с
  селектором сотрудников.

## Sync QR

Кнопка «Синхронизировать QR» в шапке — split-button с двумя вариантами:

- **Только акты** — быстро, обновляет только список документов и их статусы.
- **Акты, ингредиенты и склады** — полная синхронизация.

Кнопка видна тем, у кого есть право `inventory.sync_quickresto`.

## Колонки и пагинация

Колонки можно скрывать, переставлять и менять ширину — настройки сохраняются
в браузере. Ширину столбца нельзя сузить меньше его заголовка, а шапка таблицы
остаётся видимой при прокрутке. Сортировка по `№`, `Дата`, `Статус` — кликом по
заголовку (asc → desc → off). Пагинация: 25 / 50 / 100 строк на странице, при
смене фильтра номер страницы автоматически сбрасывается на 1.

### Исполнитель и проверяющий

Пока акт можно редактировать, в этих столбцах — выбор сотрудника (если у вас
есть право назначать). **Когда акт завершён** (проведён), исполнитель и
проверяющий становятся ссылками: клик открывает страницу сотрудника напрямую,
а хлебная крошка там ведёт обратно — «Акты инвентаризации». Ссылка появляется
только если у вашей должности есть **доступ к разделу «Сотрудники»**; иначе
просто отображается имя.

### Итоги

Одно число — нетто-расхождение по акту (излишки минус недостачи). **Плюс**
(излишек) подсвечивается зелёным, **минус** (недостача) — красным. Прочерк —
если у акта ещё нет посчитанных итогов.

## Кто что видит — модель доступа

- **Линейный сотрудник** (только `inventory.fill_assigned_documents`): видит
  только акты, назначенные на него; фильтра «Назначен» нет; меню «⋯» без
  «Изменить назначение».
- **Менеджер** (`inventory.view_documents` + `inventory.manage_documents`,
  но без `view_all_venues`): видит акты заведений своего членства, может
  переназначать.
- **Менеджер с расширенным доступом** (`+ inventory.view_all_venues`):
  видит все акты аккаунта.
- **Владелец**: всё.

## Известные ограничения

- Сохранённые представления — только локально (localStorage), не
  синхронизируются между устройствами.
- Bulk-операции (передать несколько актов разом, отметить как просмотренные)
  пока не поддерживаются — _TBD_.
- Объединённый экран акта (Заполнение и Итоги в одном URL с табами) — в
  следующем релизе. Сейчас два URL, переключение через меню «⋯» или через
  кнопку в шапке акта.
- Автодетект больших расхождений и отправка на пересчёт — в плане,
  отдельный модуль контроля.
