# Документы

В разделе «Документы» три пункта меню:

- **Акты инвентаризации** — подсчёт остатков, итоги, пересорт и пересчёт.
  Подробно — в разделе [«Инвентаризация»](../inventory/index.md).
- **Приходные накладные** — накладные поставщиков за месяц и подтверждение
  их оплаты расходами из финансов. Подробно — на странице
  [«Приходные накладные»](./supplies.md).
- **Списания** — журнал актов списания, которые сотрудники оформляют в
  Quick Resto: разбилась посуда, испортился продукт, сотрудник взял что-то
  для себя. Подробно — на странице [«Списания: кто платит»](./writeoffs.md).

У каждого экрана есть справка: кнопка «?» в верхней панели.
