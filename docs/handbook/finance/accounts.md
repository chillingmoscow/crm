# Счета

Счёт — касса, расчётный счёт, карта, фонд или сейф. Балансы пересчитываются автоматически по транзакциям.

## Архивирование и удаление

В карточке счёта (внизу, блок «Опасная зона») — две кнопки.

### Архивировать

**Что делает:** скрывает счёт из всех выборов в новых транзакциях. Существующие транзакции сохраняют ссылку — история и баланс по ним не теряются.

**Подтверждение:** ввод точного названия счёта.

**Кто может:** только владелец аккаунта.

**После архивации:** уведомление с кнопкой «Отменить» на 15 секунд.

### Удалить навсегда

**Это редкий случай.** Счёт нельзя удалить пока на него ссылаются транзакции — это RESTRICT на уровне БД. Удалить навсегда возможно только если по счёту нет ни одной транзакции (новый счёт, созданный по ошибке).

В большинстве случаев нужно «Архивировать» — данные сохранятся.

**Кто может:** только владелец аккаунта (`finance.delete_bank_account`).

### Архив

`/finance/accounts/archive` — owner-only. Ссылка «Архив (N)» появляется в шапке списка если есть архивные счета.

## FAQ

- **«Удалить навсегда» не работает / показывает транзакции** — есть финансовая история. Используйте «Архивировать».
- **В выборе счёта для транзакции нет нужного** — он в архиве. Восстановите из `/finance/accounts/archive`.
- **Раньше был чекбокс «Показать удалённые»** — заменён на отдельную страницу архива (только владелец).
