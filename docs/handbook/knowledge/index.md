# База знаний (Knowledge)

> Это справка по фиче «Knowledge» внутри приложения, где **вы сами создаёте свои статьи**. Не путать с самим handbook'ом, в котором вы сейчас читаете.

## Что это

_TBD_ — раздел, где пользователь ведёт свою иерархическую базу знаний (страницы с rich-text редактором, древовидная структура, свойства).

## Главная

При входе в раздел сотрудник видит персональную главную:
приветствие по имени, блок **«Обязательное чтение»** с прогрессом
(сколько обязательных статей прочитано из общего числа) и списком
непрочитанных, сетку **«Недавно обновлённые»**, а также **«Мои
недавние»** и **«Избранное»**. Пустые блоки скрываются; если в
базе вообще ничего нет — показывается подсказка.

Кнопка **«Новая страница»** видна только при праве создавать
страницы. Пользователь с доступом к аналитике базы знаний вместо
этой главной сразу попадает на [Дашборд](#дашборд).

## Аудит

Создание / изменение / переименование / перемещение / удаление /
восстановление KB-страниц, а также блокировка от редактирования и
пометка «обязательно к прочтению» автоматически пишутся в журнал.

Отдельной страницы журнала базы знаний больше нет — всё в **общем
[Журнале событий](../org/audit.md)** (`/org/audit`). Чтобы видеть
только базу знаний, в фильтре **«Раздел»** выберите «База знаний»
(кнопка «Весь журнал» на дашборде сразу открывает его с этим
фильтром). Рядом — фильтр **«Действие»** (Создание / Изменение /
Удаление / Восстановление / Перемещение), работает для всех
разделов.

Название страницы в записи журнала кликабельно — ведёт на саму
страницу (если она ещё существует и не в корзине). У событий
удаления для тех, кто может удалять страницы, есть компактная
кнопка-иконка **«Восстановить»** (с подсказкой при наведении) —
возвращает страницу с веткой из корзины прямо из журнала.

Факт изменения страницы фиксируется в журнале **один раз на сессию
редактирования** (правки одного автора за ~15 минут сворачиваются в
одну запись «изменил(а) страницу») — журнал не засоряется по строке
на каждое автосохранение. Комментарии изменением не считаются.
Детальная история правок (по версиям) — во вкладке «История
версий» на самой странице, не в журнале.

## Дашборд

Раздел `/knowledge/dashboard` (доступ — у кого есть аналитика базы
знаний или просмотр журнала). Один экран со всей сводкой —
объединяет бывшие «Дашборд» и «Аналитику» (старая ссылка
`/knowledge/analytics` теперь ведёт сюда же).

- Сверху — переключатели **периода** (День / Неделя / Месяц) и
  **вида** (Обзор / По страницам). Период и вид сохраняются в
  ссылке — дашборд можно отправить коллеге.
- Карточки-показатели: всего страниц (и сколько добавилось за
  период), активных читателей (из размера команды), среднее время
  одной сессии, сколько человек прочитали все обязательные
  страницы, число изменений за период. Засчитывается только
  активное время чтения; значок «?» в правом верхнем углу (слева
  от колокольчика уведомлений) по клику открывает понятное
  пояснение, как именно считается время (без технических терминов).
- **Обзор**: «Самые читаемые страницы» (топ-5, клик ведёт на
  разбивку по читателям конкретной страницы) и «Активные
  сотрудники» (топ-3).
- **По страницам**: полный список страниц с временем чтения за
  период.
- Блок **«Активность по месяцам»** — столбики по месяцам (видна
  динамика). График не показывает месяцы до создания аккаунта: у
  нового заведения первый столбец — месяц регистрации, а не пустой
  прошлый год. Дальше окно растёт с каждым месяцем, но не более чем
  за последние 12. Клик по столбцу открывает дашборд за этот
  конкретный месяц (показатели и списки пересчитываются за него);
  кнопка «← к периоду» возвращает к скользящему периоду.
- Внизу всегда — лента **«Последние изменения»** со ссылкой на
  полный журнал.

Разделы для менеджера (**Дашборд**, **Журнал**, **Корзина**)
собраны в одну секцию «Инструменты менеджера» внизу бокового
дерева базы знаний; активный раздел подсвечивается. Видимость
каждого пункта зависит от ваших прав.

## Поиск

Открывается по `⌘K` / `Ctrl+K` из любого места или по иконке-лупе.

- Печатайте запрос — результаты ищутся по заголовкам и содержимому
  страниц, совпадения подсвечиваются. Поиск работает и по началу
  слова в заголовке: достаточно ввести несколько первых букв
  (включая короткие запросы и предлоги вроде «за»). То же и в меню
  упоминаний по `@` в редакторе.
- Если ИИ отвечает «в базе знаний нет страниц для ответа», хотя
  статьи есть — нужно один раз нажать **«Переиндексировать для
  ИИ»** в шапке [Дашборда](#дашборд). Кнопка видна тем, кто может
  пользоваться ИИ-поиском (при включённом ИИ) и проиндексирует все
  страницы; жать повторно безопасно. Это требуется для контента,
  созданного до включения ИИ — новые и изменённые страницы
  индексируются автоматически при сохранении.
- Если включён ИИ-поиск, под строкой поиска всегда виден голубой
  блок **«Спросить ИИ о базе знаний»**. Нажмите **Enter** (или
  кликните по блоку), чтобы задать вопрос своими словами и получить
  ответ со ссылками на источники. Если ИИ-поиск временно недоступен
  (например, не настроен ключ), вместо ответа появится сообщение
  «ИИ-поиск временно недоступен. Обратитесь к администратору».
- Навигация по результатам — стрелками, открыть — кликом, закрыть —
  `Esc`.

## Обязательное чтение

Страницу можно пометить как **обязательную к прочтению** (право
«Управлять обязательным чтением»). На такой странице сверху во всю
ширину висит жёлтая плашка «Требуется прочтение» (или «Страница
обновлена», если содержимое изменилось после вашего прежнего
подтверждения) с кнопкой **«Прочитано»** и примерным временем
чтения.

Кнопка становится активной не сразу: нужно провести на странице
достаточно активного времени (порог зависит от объёма статьи) —
нельзя «прокликать» обязательную страницу, не открыв её. Пока
порог не набран, кнопка неактивна, а при наведении поясняет, что
нужно ознакомиться со страницей. Учитывается **накопленное**
активное время по всем заходам (время вне вкладки не считается):
если вы уже читали страницу раньше или она обновилась — заново
вычитывать полный порог не нужно. После подтверждения плашка
сменяется зелёной отметкой «Прочитано».

## Блокировка от редактирования

Страницу можно заблокировать от случайных правок. У заблокированной
страницы в верхней панели рядом с кнопкой ⋯ появляется чип
**«Заблокировано»** (он не занимает места в теле страницы). Клик по
чипу открывает меню:

- **Редактировать** — снять блокировку только для себя (другие
  по-прежнему видят страницу заблокированной);
- **Разблокировать** — снять блокировку для всех (нужно право
  «Блокировать страницы»).

Когда вы разблокировали страницу для себя, чип показывает
«Разблокировано» — клик по нему снова заблокирует её для вас.

## История версий

Во вкладке «История версий» можно открыть **снимок версии** —
страницу только для чтения на момент сохранения (комментарии и лента
обновлений в снимок не входят). Восстановление создаёт новую текущую
версию страницы, прежние версии при этом не теряются.

История версий доступна только при праве **«Смотреть историю
версий страниц»** (группа прав «База знаний»). По умолчанию оно
есть у владельца, управляющего, администратора и бухгалтера; у
рядовых сотрудников — нет, и пункт «История версий» в меню
страницы им не показывается.

## Коллекции

Если на странице есть блок «Коллекция», выделенную ячейку можно
**очистить** клавишей `Backspace` или `Delete` — очищается именно
значение ячейки, сам блок коллекции при этом не удаляется.

## Корзина

Удалённые страницы попадают в **Корзину** (`/knowledge/trash`,
доступ — у тех, кто может удалять страницы). Что важно знать:

- Удаление каскадное: вместе со страницей в корзину уходят все её
  подстраницы. При восстановлении вся ветка возвращается в той же
  иерархии.
- Рекомендуемый срок хранения — **30 дней**. У каждой строки виден
  остаток этого срока («осталось N дней»); ближе к концу он
  подсвечивается оранжевым — пора решить, восстановить или удалить
  навсегда. Освобождать корзину пока нужно вручную (кнопка «Очистить
  корзину»).
- Поиск по названию вверху фильтрует список.
- Можно отметить несколько страниц галочками — внизу экрана
  появится плавающая панель с групповыми действиями
  (**Восстановить** / **Удалить навсегда** / снять выделение). Она
  не привязана к верху списка: выделять можно где угодно, не
  прокручивая наверх.
- Кнопка **Очистить корзину** удаляет всё содержимое безвозвратно.
- «Удалить навсегда» и «Очистить корзину» необратимы и всегда просят
  подтверждение.
- Иконка-глаз у строки открывает саму удалённую страницу
  **только для чтения** (как в Notion): сверху висит баннер «в
  корзине» с кнопками «Восстановить» и «Удалить навсегда».
  Восстанавливать для просмотра не нужно.
- Удалённую страницу можно открыть и из ссылок — название в
  Журнале событий и упоминание-чип в тексте другой страницы
  остаются кликабельными, но показываются серыми и зачёркнутыми.
- Сотрудник без права удалять страницы при переходе по ссылке на
  удалённую страницу видит понятное сообщение «Недостаточно прав,
  обратитесь к администратору» (а не ошибку «страница не найдена»).
  Содержимое удалённой страницы ему при этом не показывается.
  Клик ведёт на тот же read-only просмотр с баннером.
