# Статистика на экранах людей: варианты

31 октября 2026. Владелец выбрал раскрываемый «Обзор» по кнопке и запросил два макета: сотрудники и кандидаты. Макеты обеих страниц одобрены. Реализация подключена к данным CRM, проверена локально; выпуск отдельно.

## Компактная сводка над списком

Одна невысокая полоса между заголовком и таблицей, без сетки крупных карточек.

- Сотрудники: работают сейчас, принято за месяц, средний стаж действующих сотрудников. Под стажем небольшая горизонтальная шкала по группам: до месяца, 1–3 месяца, 3–12 месяцев, больше года.
- Кандидаты: новые, ожидают собеседования, проходят стажировку. Рядом распределение анкет по текущим этапам.
- Нажатие показателя с однозначным соответствием фильтру применяет этот фильтр к списку. Остальные показатели имеют пояснение расчёта.
- На телефоне показатели переходят в две строки, график остаётся небольшим.

Подходит для быстрого ежедневного обзора. Постоянно занимает место перед списком.

## Обзор по кнопке — рекомендуемый вариант

Нейтральная кнопка с иконкой графика в ряду инструментов. По нажатию раскрывается компактный блок над списком. При каждом новом открытии страницы он свёрнут; данные запрашиваются только после раскрытия.

- Сотрудники: состав по должностям и группам стажа. При наличии достоверных дат — принято/уволено по месяцам за выбранный период.
- Кандидаты: распределение по этапам и поступление анкет по неделям; отдельно количество наймов из анкет выбранного периода.
- Достаточно двух простых диаграмм и двух-трёх чисел. Основная таблица остаётся рабочим центром страницы.
- На телефоне диаграммы идут последовательно, без горизонтальной прокрутки.

Подходит для страницы, которой пользуются и для работы со списком, и для периодического анализа. По умолчанию свёрнут.

## Сводка в боковой панели

Та же кнопка графика открывает общую боковую панель со сводкой и выбором периода.

- Сотрудники: стаж и движение команды, затем распределение по должностям.
- Кандидаты: текущие этапы, скорость первого разбора, наймы из анкет выбранного периода.
- Список не сдвигается; на телефоне панель занимает экран целиком.

Подходит, если приоритет — сохранить максимальную высоту таблицы. Одновременно сравнивать сводку и строки менее удобно.

## Определения и ограничения данных

- «Работают сейчас» — действующие сотрудники выбранного заведения; приглашения не входят в штат.
- «Средний стаж» — среднее время с указанной в карточке даты трудоустройства у действующих сотрудников. Это не средняя продолжительность завершённой работы.
- «Средняя продолжительность работы уволенных» — от указанного начала работы до увольнения. В текущем наборе данных списка уволенных дата начала не передаётся; для этой метрики нужно дополнить выборку.
- Дата создания/импорта профиля не заменяет указанную дату начала работы. Если дата неизвестна, запись исключается из расчёта стажа, а рядом указывается покрытие данных.
- Диаграмма текущих статусов — распределение, не конверсионная воронка. Этапы можно менять вручную; нельзя выдавать число анкет в каждом текущем статусе за число прошедших этап.
- Конверсия в найм считается для одной группы анкет по дате поступления, с учётом уже принятых сотрудников. Нельзя делить наймы этого месяца на все поступления другого периода.
- Для исторической воронки нужны события и назначения, с отдельной обработкой старых импортированных анкет, у которых история этапов может быть неполной.
- Графики считаются по всей разрешённой выборке, а не по текущей странице таблицы. Сотрудники относятся к заведению, кандидаты общие для аккаунта.
- Конкретные числа и проценты в макетах будут помечены как примеры до подключения расчётов.

## Реализованные правила после проверки владельцем

- «Обзор» по умолчанию свёрнут, данные запрашиваются после раскрытия. Поиск, фильтры, страница таблицы и переключение действующие/уволенные не меняют расчёты.
- Сотрудники относятся к выбранному заведению. В обзоре оставлены только средний стаж и распределение действующей команды по стажу. Численность, приём за месяц и движение команды убраны как не помогающие владельцу в работе.
- Стаж рассчитывается на сегодня в часовом поясе заведения, поэтому выбор месяца у сотрудников убран. Используется исходное `staff_account_details.employment_date`, без подстановки даты создания или импорта профиля. Неизвестные и будущие даты исключаются; покрытие указано под графиком.
- Кнопка уволенных находится перед «Обзором», который стоит непосредственно перед «Добавить».
- У кандидатов убраны три отдельные метрики: «Поступило», «Новые анкеты», «Принято». Сохранены поступление по дням, накопительная воронка и компактная полоса текущих этапов с легендой и числами.
- Кандидаты образуют одну когорту по месяцу `submitted_at` в Europe/Moscow. Выбор месяца независим от таблицы; будущие месяцы недоступны. Для текущего месяца график заканчивается сегодняшним днём, не выдавая будущие дни за нулевой отклик.
- Воронка: получены анкеты → рассмотрение → собеседование → стажировка → приняты. Учитывается максимальный когда-либо достигнутый этап и все предыдущие, как подтвердил владелец. Доля каждого этапа рассчитывается от всех анкет выбранного месяца. Пропущенный вручную ранний этап включается в предыдущие ступени накопительно.
- Источники воронки: текущий статус, прежнее и новое значение статуса в `candidate_events`, текущие назначения и сохранённые снимки назначений из событий. Существующий триггер записывает каждое изменение статуса; отдельные дублирующие записи истории не создаются.
- Отказ после собеседования, отмена назначения или возврат на ранний этап не вычитают кандидата из ранее достигнутой ступени. Несколько стажировок и повторные переходы не увеличивают количество кандидатов. Собеседование и стажировка в воронке означают назначение, а не подтверждённое посещение или успешный результат.
- Для анкет из Notion видна пометка о неполной истории до переноса. Из одного текущего отказа нельзя восстановить неизвестные прошлые этапы. Известный более поздний этап позволяет включить все предыдущие по согласованной накопительной логике.
- Принятые входят в воронку и график поступлений, но исключены из рабочего списка и полосы текущих этапов. Поэтому, например, 29 анкет в воронке и 28 в заголовке списка означают одну принятую анкету, а не разные результаты подсчёта. Это объясняется в подсказке к воронке.
- Удалённые и архивные анкеты исключены из всех диаграмм. Расчёт не зависит от ограничения страницы или API в 1000 строк. Ошибка чтения не подменяется нулями.
- Доступ: `people.view_staff` для команды, `people.manage_candidates` для кандидатов. Scope определяется серверным активным контекстом и сверяется с открытой страницей. Воронка выполняется с RLS; браузер получает только агрегаты.
- История и назначения материализуются один раз для когорты, чтобы плохая оценка числа недавно импортированных анкет не приводила к повторной проверке одних и тех же строк.
- При повторном раскрытии, возвращении фокуса, новых анкетах и изменении статуса открытый обзор обновляется. На телефоне диаграммы располагаются последовательно, текущие этапы компактно переносятся в легенде. Таблица сохраняет вид карточек.

## Дополнительные идеи для сотрудников, пока без реализации

1. **Стаж по должностям.** Медиана стажа и доля работающих меньше трёх месяцев среди барменов, мастеров и менеджеров. Помогает увидеть, в какой части команды больше новичков; можно посчитать по имеющимся датам найма и должностям.
2. **Продолжительность работы до увольнения.** Медиана и распределение завершённых периодов работы. Показывает, насколько долго люди обычно остаются в команде. Нужны обе достоверные даты; неизвестные периоды исключаются, повторный найм требует отдельного учёта.
3. **Удержание новичков через 30 и 90 дней.** Доля принятых за выбранный период, продолживших работу после соответствующего срока. Только для уже «дозревших» групп; прежде нужно проверить полноту истории увольнений и повторного найма.
