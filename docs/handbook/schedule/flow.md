# График работы: поток и правила

Главная задача руководителя: составить неделю и опубликовать смены. По умолчанию экран содержит только вкладки, неделю, календарь и действия. Фильтры и панель шаблонов раскрываются отдельно. Цвет обозначает шаблон смены; текст «Черновик» обозначает её состояние. Пустая ячейка создаёт смену, карточка открывает её подробности. На телефоне расписание показывается списком по дням.

1. Подразделения и должности берутся из существующего раздела «Люди». Дополнительные позиции разрешают назначать смены, но не изменяют права доступа.
2. Руководитель создаёт чек-лист: тип, подразделение, длительность, приоритет и упорядоченные пункты (чекбокс, фото, число, текст, информация). Подпункты группируются под родительским пунктом. Публикация делает чек-лист доступным для назначения.
3. Шаблон содержит название, цвет, время, перерыв, ранний приход и чек-листы. Архивирование сохраняет существующие смены.
4. Смена создаётся по шаблону либо вручную. Для неё можно изменить сотрудника, должность, время и чек-листы. Ночные смены заканчиваются следующим днём. Время показывается в часовом поясе заведения. Пересекающиеся смены одного сотрудника запрещены.
5. Черновики доступны планировщикам. Сотрудники видят только свои опубликованные смены. Публикация недели применяет текущие фильтры и требует отдельного права. Копирование создаёт черновик.
6. Сотрудник открывает свою смену и начинает чек-лист. При публикации смены фиксируются опубликованные версии чек-листов. На старте выполнения используется этот снимок: последующее изменение или архивирование шаблона не меняет уже назначенные задачи. Ответы сохраняются автоматически с явным статусом сохранения. Отправка возможна после обязательных пунктов.
7. Проверяющий просматривает ответы и фотографии, утверждает выполнение либо возвращает с комментарием. Сотрудник исправляет ответы и повторно отправляет. Утверждённые ответы блокируются. История хранит изменения смен и переходы статуса выполнения.

## Права

Отдельные разрешения: просмотр всей команды, создание, изменение, копирование, удаление, назначение сотрудников и публикация смен; создание, изменение, копирование и архивирование шаблонов; создание, изменение, публикация и архивирование чек-листов; проверка выполнения; управление дополнительными позициями. Настройка находится в существующей карточке должности. Собственные опубликованные смены доступны активному сотруднику без права просмотра всей команды.
