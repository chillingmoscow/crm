# Юридические лица

Юрлицо — субъект, от имени которого выставляются счета и оформляются
транзакции (ИП, ООО, АО). К одному аккаунту может быть привязано
несколько юрлиц; к одному юрлицу — несколько заведений.

## Как пользоваться

1. **Создать** — `/org/legal-entities` → «Создать юрлицо». Введите ИНН —
   реквизиты подтянутся из ДаДата.
2. **Редактировать** — клик по строке.
3. **Привязка к заведению** — на карточке заведения поле «Юрлицо по
   умолчанию». Архивные юрлица в выборе не показываются.

## Архивирование и удаление

В карточке юрлица (внизу, блок «Опасная зона») — две кнопки.

### Архивировать

**Что делает:** скрывает юрлицо из всех выборов: его нельзя выбрать
в новой транзакции, новом банк-счёте, новом заведении по умолчанию.
Существующие счета, транзакции и заведения **сохраняют ссылку** —
история и отчётность не теряются.

**Подтверждение:** в диалоге нужно ввести точное название юрлица.

**Кто может:** только владелец аккаунта.

**После архивации:** появится уведомление с кнопкой «Отменить» на
15 секунд.

### Удалить навсегда

**Это редкий случай.** Юрлицо нельзя удалить пока на него ссылаются:
- банк-счета (счета теряют смысл без юрлица),
- транзакции (финансовая история),
- заведения (как юрлицо по умолчанию).

Если хоть одна привязка есть — кнопка покажет блокеры и подсказки,
что сделать. В большинстве случаев правильное действие — **архивировать**:
данные сохраняются, а юрлицо перестаёт появляться в выборах.

Удалить навсегда возможно только если все привязки сняты вручную
(например, после миграции данных или закрытия деятельности).

**Подтверждение:** диалог требует ввод названия + показывает блокеры
если они есть. Без блокеров — кнопка активна.

**Кто может:** только владелец аккаунта.

### Архив

Раздел `/org/legal-entities/archive` (ссылка «Архив (N)» появляется в
шапке `/org/legal-entities` для владельца если есть архивные юрлица).

В нём — все архивные юрлица с датой и автором архивации.
Действия:
- **Восстановить** — снова появится во всех выборах.
- **Удалить навсегда** — повторное подтверждение, проверка блокеров.

**Доступ:** только владелец аккаунта.

## FAQ / частые ошибки

- **«Удалить навсегда» не работает / показывает блокеры** — у юрлица
  есть финансовые привязки. Архивируйте — это правильное действие.
- **В выборе юрлица для заведения / транзакции нет нужного** — он,
  скорее всего, в архиве. `/org/legal-entities/archive` → восстановить.
- **Раньше была кнопка «Деактивировать», теперь «Архивировать»** —
  это одно и то же: миграция 200 переименовала `is_active` в более
  единообразный `archived_at` (новый стандарт для всех модулей,
  см. `docs/CONVENTIONS.md`).

## Известные ограничения

- Архив не имеет авто-очистки.
- При hard-delete уничтожаются загруженные документы (вложения), если
  все остальные блокеры сняты. Скачайте важное заранее.
