# Документы: списания

Раздел «Документы» → «Списания» — журнал актов списания, которые сотрудники
оформляют в Quick Resto: разбилась посуда, испортился продукт, сотрудник взял
что-то для себя. Акты инвентаризации живут рядом, в разделе
[«Инвентаризация»](../inventory/index.md).

Подробности — на странице [«Списания: кто платит»](./writeoffs.md).
