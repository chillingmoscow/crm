# Дашборд финансов

## Что это

Сводка денег за выбранный период: остаток на счетах, доходы, расходы,
расходы по статьям, остатки по каждому счёту и последние операции.
Открывается из меню «Финансы → Дашборд».

## Для кого / когда использовать

Владельцу, бухгалтеру и управляющему — чтобы за минуту понять, сколько денег
сейчас и куда они уходили за месяц, без фильтров в журнале операций.
Нужен доступ к дашборду; показатели по операциям и счетам видны, только если
есть доступ к операциям и к счетам. Без доступа вместо суммы стоит прочерк с
причиной.

## Как пользоваться

1. **Период.** По умолчанию — текущий месяц. Стрелки переключают на соседний
   период той же длины (месяц на месяц, неделю на неделю, год на год).
   Нажмите на период, чтобы выбрать готовый вариант («Прошлый месяц», «Этот
   квартал», «Последние 30 дней» и т. п.) или отметить даты в календаре и
   нажать «Применить». «Сегодня» возвращает к текущему месяцу. Период
   сохраняется в адресе страницы — ссылкой можно поделиться.
2. **Фильтры.** Кнопка с воронкой открывает выбор юрлица и заведения (если
   их больше одного и есть право видеть все). Выбранное юрлицо запоминается
   и действует во всех разделах финансов. «Очистить все» снимает оба фильтра.
3. **Показатели.**
   - «На счетах» — остаток на всех счетах сейчас; период на него не влияет,
     счета, исключённые из баланса, не учитываются. Фильтр по заведению
     остаток не меняет: счета часто общие. Нажмите — откроется список счетов.
   - «Доходы» и «Расходы» — суммы операций за период. Нажмите — откроется
     журнал операций с доходами или расходами за этот период.
   - «Чистый поток» — доходы минус расходы. Переводы между своими счетами
     не входят ни туда, ни туда.
   - **Сравнение.** Под доходами и расходами — изменение в процентах к
     прошлому периоду той же длины и к тому же периоду год назад: «+12% к
     октябрю», «−3% к ноябрю 2025». Рост расходов красный, рост доходов
     зелёный. Под чистым потоком — разница в рублях. Идущий месяц
     сравнивается по прошедшим дням: 1–21 ноября с 1–21 октября, а не со всем
     октябрём. Если в периоде для сравнения операций не было, строки нет.
     Наведите на строку — увидите прежнюю сумму.
4. **Расходы по статьям.** Пять крупнейших статей периода, доля каждой — от
   всех расходов периода. Остальные статьи собраны в одну строку. Нажмите на
   статью — откроется журнал операций с этой статьёй за тот же период.
5. **Остатки на счетах.** Каждый счёт, который входит в общий остаток, по
   убыванию суммы; минус выделен красным. Нажмите на счёт, чтобы открыть его.
6. **Добавить операцию.** Кнопка в шапке: выберите приход, расход или
   перевод — откроется журнал операций с уже открытой формой. Кнопка видна,
   если есть право заводить операции.
7. **Последние операции.** Восемь последних операций периода с учётом
   фильтров. «Все операции» открывает журнал с теми же условиями.

## FAQ / частые ошибки

- **Почему «На счетах» не поменялся при смене месяца?** Это остаток на
  сегодня, а не за период.
- **Почему сравнение с «1–21 октября», а не с октябрём?** Месяц ещё идёт:
  сравнивать незаконченный ноябрь с целым октябрём значило бы всегда видеть
  спад. Когда месяц закончится, сравнение пойдёт с целым прошлым месяцем.
- **Почему в «Доходах» нет перевода из кассы на расчётный счёт?** Перевод
  между своими счетами — не доход и не расход.

## Известные ограничения

- Операции, заведённые вперёд датой позже сегодняшней, входят в сумму
  периода, но не в сравнение.
- Суммы в разных валютах складываются без пересчёта курса.
- Перевод между двумя юрлицами при фильтре по одному юрлицу не считается его
  доходом или расходом.
